DIUU BIRTHDAY WEBSITE — COMPLETE PACKAGE

CONTENTS
- index.html: website page using separate CSS and JavaScript files
- style.css: all styles, responsive layout, and animations
- script.js: interactions, balloon pop effects, scene changes, and generated theme music
- bestie_birthday.html: standalone all-in-one version (HTML + CSS + JavaScript in one file)

HOW TO OPEN
1. Extract this ZIP file.
2. For the separated source-code version, keep index.html, style.css, and script.js together in the same folder.
3. Open index.html in a modern browser.
4. Or open bestie_birthday.html for the standalone version.

NOTES
- Music starts after a user interaction because mobile browsers usually block autoplay.
- The site is packaged locally; to share a public tap-to-open URL, it must be uploaded to a hosting service.
